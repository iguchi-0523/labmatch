# ラボマッチ フェーズ0 — 利用可否 照会文ドラフト

作成：2026-05-22

researchmap（JST）と CiNii Research（NII）に、API の利用可否を確認するための問い合わせ文ドラフト。

## 送付方法・メモ
- researchmap：researchmap 公式サイトのお問い合わせ窓口から送付。
- CiNii：国立情報学研究所（NII）の公式サポートサイトのお問い合わせ窓口から送付。
- KAKEN：KAKEN API のアプリケーションID は CiNii と共通の開発者登録で取得できる。KAKEN 自体は出典明記で商用利用可（CC BY 相当）と確認済みのため、別途の照会は不要。
- 送付前に［お名前を記入］［メールアドレスを記入］を埋めること。サイトの説明資料や想定URLを添えると回答が早い。
- 回答が得られたら、要件定義書 6.1 / 第12章 のリスク記述を更新する。

## 1. researchmap（JST）宛

```
件名：researchmap API の利用可否についてのお問い合わせ

researchmap 運営事務局 御中

突然のご連絡失礼いたします。私は、大学の研究室情報を分野・大学などの軸で検索できる一般向けWebサイト「ラボマッチ」の開発を個人で進めている者です。本サイトは、大学院進学や研究室配属を検討する学生が、自分の興味に合う研究室を見つけやすくすることを目的としています。

本サイトの研究室情報の一部に researchmap の公開データ（研究者の所属、所属学協会、委員歴、研究キーワード、業績など）を活用し、あわせて各研究者の researchmap ページへのリンクを掲載したいと考えております。つきましては、researchmap API（researchmap.V2 利用申請）の利用について、以下の点をご教示いただけますでしょうか。

1. 大学等の研究機関に所属しない個人開発者が、researchmap API の利用申請を行うことは可能でしょうか。
2. 可能でない場合、個人が researchmap のデータを API 経由で利用する方法はございますでしょうか。
3. 取得したデータを、上記のような研究室情報の検索・表示を行う一般公開Webサイトに掲載する用途は、利用範囲として認められますでしょうか。
4. 当該Webサイトが、運営費を賄うために広告などの収益を伴う場合でも、API の利用は可能でしょうか。
5. 利用が可能な場合、申請の具体的な手順と、遵守すべき条件（出典表示など）をご教示ください。

お忙しいところ恐れ入りますが、ご回答のほどよろしくお願い申し上げます。

氏名：［お名前を記入］
連絡先：［メールアドレスを記入］
```
